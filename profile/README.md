# FolderSizes Pro — disk map of folder growth you own

FolderSizes Pro keeps one named board on the desk: the live tree, the folder report in front of you, and a short note the next operator can read. Extra maps wait for their own title.

## Session Card

| Slice | What you do in FolderSizes Pro | What remains |
|-------|------------------------|--------------|
| Arrival | Open FolderSizes Pro and name today's scan desk | A titled disk map |
| Focus | Keep only live folders on the FolderSizes Pro board | A short tree |
| Check | Read FolderSizes Pro space charts before a large scan change | A confirmed scan desk |
| Handoff | Mark finished maps inside FolderSizes Pro | A note for the next operator |

## How FolderSizes Pro Sits

FolderSizes Pro does not replace a guess about growth, the unlabeled tree dump, or a map of a volume you do not own. It sits beside them as a named scan desk for one job: which disk map is live, which folder report still matches space charts on a volume you own, and what the next operator should read.

## Traffic Light

| Signal | On the FolderSizes Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named disk map, short live tree | Continue the same folder report |
| Amber | Two volumes mixed on one space chart | Split the tree before a large change |
| Red | No title, no note, a guess about growth | Stop and name the scan desk first |
| Clear | Handoff written, live maps few | Close FolderSizes Pro and leave the scan desk |

## Open Order

1. Open the last FolderSizes Pro scan desk, not a new empty disk map.
2. Read the folder report and the last handoff.
3. Finish one visible space-chart pass inside FolderSizes Pro on a volume you own.
4. Write what changed, then close with fewer growth guesses than you found.
5. If the tree feels crowded, drop anything that belongs to a different FolderSizes Pro volume.

## After a Week

A week in FolderSizes Pro is not a larger guess about growth. It is the same title, a shorter live tree, and a note that still makes sense before the next folder report. Take finished maps off the live set so the next visit starts on the scan desk that is still open.

## Sign-off

- [ ] The FolderSizes Pro workspace name is short enough to scan
- [ ] Only a volume you own sits on the disk map
- [ ] A second operator can read the folder-report handoff

## Field Note

FolderSizes Pro is easier to trust when the scan desk stays smaller than the unlabeled tree dump it came from. Name the disk map, keep the live folders, finish one visible space-chart pass, and write what changed.
